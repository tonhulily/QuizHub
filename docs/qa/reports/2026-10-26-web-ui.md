- Source app: `b949513b254bee55a3887e619786ea91f85b477f`; tracked `lib/` và `assets/` đúng SHA này, không sửa source app.
- Chromium headless qua Playwright MCP hiện có. Lecturer: `127.0.0.1:4173`, viewport `1280×720`; student: `127.0.0.1:4174`, viewport `390×844`.
- Flutter 3.41.6 / Dart 3.11.4; web build cho hai role exit 0. Preview backend lưu thay đổi trong RAM; API host và thiết bị native: NONE.
- Tracked evidence: [case summary and screenshots](../evidence/2026-10-26/web-ui/web-ui-summary.md). Detailed snapshots, console/build logs remain ignored in `qa-artifacts/2026-10-26/web-ui/` and are local-only.

## Giới hạn và ghi chú

- Không chạy backend thật, API acceptance, Android/iOS hoặc kiểm thử native trên điện thoại. Kết quả web mock không thay thế các case đó.
- Console của mỗi role có 4 lỗi CORS khi tải ảnh avatar ngoài từ `i.pravatar.cc`; các lỗi chỉ liên quan ảnh preview bên thứ ba. Có cảnh báo WebGL hiệu năng ở lecturer; không làm dừng các luồng đã chạy.
- Snapshot không phải ảnh lỗi; không có screenshot lỗi được tạo trong lượt này.
- Ba lỗi P2 từ code review vẫn mở, xem [báo cáo review](2026-10-26-dung-review.md). Browser run không sửa hoặc retest các lỗi đó.
